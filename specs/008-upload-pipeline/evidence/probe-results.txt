P1  presigned PUT signed headers   probes/presign-headers.cs   AWSSDK.S3 4.0.104.8, S3ClientFactory settings
    default (ContentType set, nothing else) : X-Amz-SignedHeaders=content-type;host  X-Amz-Expires=900
        query keys = Algorithm, Credential, Date, Expires, Signature, SignedHeaders (no checksum param)
    same request with Headers.CacheControl   : SignedHeaders=cache-control;content-type;host   (negative control)
    same request with Metadata["x"]          : SignedHeaders=content-type;host;x-amz-meta-x     (negative control)
    same, WITHOUT RequestChecksumCalculation=WHEN_REQUIRED : still content-type;host (presign adds no
        checksum in 4.0.104.8 either way; the factory setting stays because PutObject needs it)
    S3Proxy behaviour with the default URL:
        PUT with the signed content type     -> 200
        PUT with a different content type    -> 403
        PUT with no content type             -> 403
        PUT plus an unsigned x-amz-meta-z    -> 403
        PUT 3 s after a 1 s expiry           -> 403
        GET on the PUT URL                   -> 403
    => FR-044 holds with the existing PresignPutAsync; a test must pin SignedHeaders == "content-type;host"
       so a later edit (cache-control, metadata) fails loudly instead of failing only in a live browser.
