# Data Model: Component UI Pages (003)

Nothing is persisted. These are in-memory view types and one fixture file.

## Tokens (`Gallery.Core.Design.Tokens`, single source)

| Token | Value | Used by |
|---|---|---|
| `SpaceL` / `SpaceM` / `SpaceS` | 48 / 32 / 16 px | page margin and grid gap per viewport class |
| `BreakLarge` / `BreakMedium` | 1200 / 600 px | viewport classes: large ≥ 1200, medium 600–1199, small < 600 |
| `CellRatio` | 4:3 | Tile cell |
| `TypeCaption` / `TypeBody` / `TypeBrand` | 12 / 14 / 16 px | Title, body text, Brand |
| `ColorBg` / `ColorText` / `ColorMuted` / `ColorRule` | #fff / #000 / #666 / #ddd | everything |
| `FontStack` | system-ui, -apple-system, "Helvetica Neue", Arial, sans-serif | everything (IV.22) |

These are emitted as CSS custom properties (`--space-l`, …). The `@media` literals in `.razor.css`
must equal `BreakLarge` and `BreakMedium`, which a test checks.

## ImageView (`Gallery.Core.Images`)

| Field | Type | Rule |
|---|---|---|
| `Id` | string | Lowercase hex, 16 characters. Used for keys only. |
| `Title` | string | Non-empty. |
| `Width`, `Height` | int | > 0. The full-size pixel dimensions. |
| `Variants` | list of `Variant { Width, AvifUrl, WebpUrl }` | Sorted ascending, non-empty. Every variant width ≤ `Width`. |
| `PlaceholderDataUri` | string | Starts with `data:image/webp;base64,`. At most about 1 KB. |
| `DominantColor` | string | `#rrggbb`. |
| `Exif` | `Exif?` | Optional. |

Derived values:
- `AspectRatio = Width / Height`
- `ThumbVariant` is the first variant with width ≥ 640, or the largest variant if none is that wide.

## Exif (`Gallery.Core.Images`)

All fields are optional: `Make`, `Model`, `Lens`, `FocalLengthMm` (decimal),
`FocalLength35Mm` (int), `FNumber` (decimal), `ExposureSeconds` (decimal), `Iso` (int).

`ExifFormat` turns a field into display text, or `null` when the value is absent. Absent fields
render nothing.

| Field | Rule | Examples |
|---|---|---|
| Camera | `Make` + `Model`, dropping `Make` when `Model` already starts with it (case-insensitive) | "FUJIFILM X-T5"; "Canon EOS R5" (from Canon + "Canon EOS R5") |
| Lens | as given | "XF33mmF1.4 R LM WR" |
| Focal length | `"{mm}mm"`, plus `" ({eq}mm eq.)"` when `FocalLength35Mm` is set and differs | "33mm (50mm eq.)" |
| Aperture | `"f/{n:0.0}"` | "f/2.0", "f/11.0" |
| Shutter | under 1 s: `"1/{round(1/s)}s"`; 1 s or longer: `"{s:0.#}s"` | "1/250s", "1.5s", "2s" |
| ISO | `"ISO {n}"` | "ISO 400" |

## SampleCatalog (`Gallery.Web.Ui`)

This loads `wwwroot/samples/samples.json` once at startup into `ImageView`s, and exposes them by
role: `Landscape[0..3]`, `Portrait[0..1]`, `Square`, `Panorama`, plus `All`.

`samples.json` is generated by `scripts/build-samples.sh` and never edited by hand:

```
{ "photos": [ { "id", "role", "title", "width", "height",
                "variants": [ { "width", "avif", "webp" } ],
                "placeholder", "dominantColor",
                "exif": { … } | null,
                "credit": { "author", "source", "license" } } ] }
```

Fixture EXIF sets: each landscape photo has full EXIF. One portrait photo has partial EXIF
(camera and ISO only). The panorama has none.

## ComponentEntry (`Gallery.Web.Ui.UiCatalog`)

`{ Level (Tokens|Atom|Molecule|Organism|Template), Name, Slug, PageType }`.

The 14 entries are: tokens, the 4 atoms, the 5 molecules, the 3 organisms, and 1 template. The
`/ui/` index and its tests are both driven from this list, so the list is the single source.
