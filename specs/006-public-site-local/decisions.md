# Decisions: 006 Public Site, Local Walking Skeleton

The rows that most change what you see or what can break are 1, 2, 5 and 8.

| # | Decision | Owner or default | Rationale | Pivot cost |
|---|---|---|---|---|
| 1 | The seed uses only the owner's photos in `dev-pictures/`. Galleries come from a committed, editable manifest, first generated by capture date. Titles are the file name. Originals are not stored. | **OWNER** (clarify 1-a, 2-a, 3-a, 4-a) | See the owner's own work on the site now; the manifest is the stand-in for the management UI. | Low: the manifest is plain JSON, and reseeding reconciles. |
| 2 | Test storage emulator: S3Proxy (transient), not MinIO | default | MinIO CE archived April 2026. SeaweedFS accepted a GET on a URL presigned for PUT; S3Proxy and R2 refused it (R-02 probe). The III.9 single-method property must fail in tests when broken. | Low: one fixture image and env vars. |
| 3 | R2 client: path-style, region `auto`, checksums WHEN_REQUIRED, unsigned payload only over HTTPS, presign protocol follows the endpoint | default (probe-driven) | Each was needed for R2 or for the HTTP emulator (R-02). All are set in one factory, so both targets run the same code. | Low. |
| 4 | r2.dev disabled is an owner-verified dashboard check, not automated. The automated check covers token scope only. FR-021 is amended. | default | The bucket-scoped token can't read that setting by design. Automating it needs a broader token, which works against III.9. | Low: add an account-read token later if wanted. |
| 5 | Preparation decodes once with ffmpeg to an upright, metadata-free PNG, then encodes everything from it | default (probe-driven) | ffmpeg 8.1 applies EXIF orientation and cwebp ignores it (R-04 probe). It's also 13× fewer 50 MP decodes. | Low. |
| 6 | Seed is a `seed` mode of the web app, not a separate project | default | It shares user-secrets, options and the storage client. D-22 rejects projects with one consumer. | Low: move to a console project later. |
| 7 | `seedKey` on galleries and images keeps random ids stable across reseeds | default | II.3 forbids ids derived from names, but shared links must survive a reseed. | Low: dropped when 009's UI replaces the manifest. |
| 8 | Public HTML `Cache-Control: public, max-age=0, s-maxage=86400`; 60 s origin output cache; measurements taken with output cache off | default | IV.18 needs a bounded edge lifetime; IV.21 needs an origin cache. Measuring with the cache on would hide the real read path. | Low: one constant. |
| 9 | View-transition names come from a per-page `<style>` block of `#p-{id}` rules | default | The inline style ban (D-21) rules out `style="view-transition-name:…"`. D-17 amended. | Low. |
| 10 | Hover preload on photo tiles only; gallery cards rely on Speculation Rules | default | A card's destination images aren't known, and preloading the cover at the wrong size wastes bytes. D-17 amended. | Low. |
| 11 | Empty-gallery card: Tile renders an empty cell plus the title through a new optional `EmptyTitle` | default | E-16 says the card renders empty. 003's Tile required an image. | Low. |
| 12 | Gallery description: plain `<p>` under an `<h1>` title on the gallery page, page-level CSS, no new catalogue component | default | Spec assumption. One consumer, so no component (D-21 extract-on-second-consumer). | Low. |
| 13 | III.2/III.5 justified deviation for seeded content only | default | No upload path until 008. Preparation runs the same structural metadata check and fails on any hit. | Low: seeded content can be re-uploaded through 008 later. |
| 14 | Mongo `mongo:8` locally (8.3.13); Atlas M0 is 8.0 | default | Same major version. Nothing beyond 6.0 features is used. | Low. |
| 15 | Packages: MongoDB.Driver 3.13.0, AWSSDK.S3 4.0.104.8, MetadataExtractor 2.9.3, Testcontainers(+MongoDb) 4.16.0 | default | Latest stable on 2026-10-31 (R-01). | Low. |
