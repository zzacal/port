Gallery Architecture

Single-owner photo gallery · Cloudflare Free edge · Azure App Service B1 · Azure Blob · MongoDB Atlas Free (constitution 3.0.0)

Visitor request path

  • • Pages: edge cache hit, or origin via AOP + IP allowlist (D-03, D-16)
  • • Origin renders from one Atlas read; sends Server-Timing + Link preload
  • • Images: img.<domain> → Cloud Connector → Blob public (D-19)
  • • No JS needed; prerender, view transitions are enhancement (D-17)

Upload and confirm

  • • Browser builds all 12 derivatives + placeholder (D-09)
  • • Direct PUT to private/staging with a 15-min SAS (D-08)
  • • Server validates structure, rejects any metadata (D-10)
  • • Confirm copies to public + masters, then purge + warm (D-11)

Limits and accepted risks

  • • Metered ≈ $1/mo; budget alerts $7 / $10 (D-18)
  • • No claim token: first sign-in owns the site (R-01)
  • • No backups; local exports are the recovery path (R-02)
  • • Raw Blob URLs reachable: unlisted, not secret (R-04)
